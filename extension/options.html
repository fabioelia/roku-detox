Roku Detox settings

TV for the toolbar button

The toolbar button sends videos to the TV you used last in Roku Detox. To always use one TV, type its address here.

Use the extension from a web page

The Roku Detox page can also run from http://localhost or http://127.0.0.1 and use this extension to reach the TV. The page needs this extension's id to find it:

  1. Open the Roku Detox page in this browser.
  2. Open the browser console there (View > Developer > JavaScript Console) and run:
  3. Reload the page. It now shows that it's using the extension.

Published copies of the page have the id built in, so this step is only for an unpacked install. Other web addresses can't talk to the extension.

Use it from your phone

Phones can use this extension through a small relay on the internet, while this browser is open. Everything passing through it is locked with your household's own key, so the relay can't read what you send or what's on your TV.

Open this link on your phone. Anyone with it can control the TV while this browser is open, so share it only with your household.

A new link stops every old one from working.

You set up the relay once with a free Cloudflare account; see relay/README.md in the Roku Detox folder.
